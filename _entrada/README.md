# Carpeta de entrada — temporal

Aquí se suben las fotografías **en bruto**, tal como salen de la cámara o del
móvil, para que se procesen y se conviertan en los archivos definitivos de
`assets/img/obras/`.

**Esta carpeta no forma parte del sitio y no se publica.** Se vacía en cuanto
las fotos están procesadas, y los originales pesados no se conservan en el
historial del repositorio.

## Cómo subir fotos

1. Entra en esta carpeta en GitHub.
2. **Add file → Upload files**.
3. Arrastra las imágenes y confirma abajo (*Commit changes*).

Si son muchas o muy pesadas, súbelas en tandas de cuatro o cinco.
